# 自营商品特色服务

>
>
自营商品特色服务

什么是护眼无忧服务？（自营商品）
客户选购有“护眼无忧”标识的自营商品，如自订单签收之日起的
60
天内，在使用过程中眼部出现红肿、发炎、视线模糊等情况，可以在线提交售后申请，并提供有效凭证，审核通过后将为客户提供退换货服务。
服务流程：
（1）申请时间：自订单签收后
60日
（以商品送达后第2天0点开始计算）内可申请服务。
（2）申请方式：
a）登
录京东APP，点击【我的】-【退换/售后】-【申请售后】-【退货】，选择“使用后红肿、发炎、充血、视线模糊等”原因，并提供有效凭证图片。
b）登录京东APP，点击【我的】-【客户服务】-【退换/售后】-【申请售后】-【退货】，选择“使用后红肿、发炎、充血、视线模糊等”原因，并提供有效凭证图片。
（3）申请服务需提交的有效凭证：
a）使用者发生红肿、发炎的眼部症状照片；
b） 二级甲等及以上医院出具的由于客户使用购买带有“护眼无忧”服务的商品导致其出现红肿、发炎等现象的盖章医疗凭证（以下凭证三选一即可：门诊/急诊病例诊断本、医生诊断证明书、机打的医生病历诊断）；
（4）服务说明：
a）客户需确保上传的凭证为原图、内容真实有效、未经涂改和增删，如果相关凭证有人为修改的痕迹将被视为无效凭证，将无法提供护眼无忧
服务；如不配合提交相关材料，将无法享受护眼无忧服务
b）如客户有利用此服务牟利的行为，将取消客户享受此服务的权益，并将影响客户京东账号的信誉等级。
c）若您申请上门取件的地址超出了京东上门取件的范围，需要您自行委托第三方快递邮寄到京东指定地址，且请勿使用货到付款方式。在您提供有效订单号、快递单号及费用凭证，并且由京东审核通过后，运费将以余额或京豆的方式返还到您的京东账户（补偿金额请参考页面说明：
https://help.jd.com/user/issue/131-296.html
）。
