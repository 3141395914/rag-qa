# 交易纠纷处理规则

>
>
交易纠纷处理规则

定制类商品的纠纷处理（买家版）
适用范围：本规则适用于京东开放平台第三方卖家销售的商品，不适用于京东自营、虚拟、闪购及海外购的商品。
定制商品主要是指买家介入产品的生产过程，以获得符合自己的个人属性、需求以及尺寸样式的商品，例如：将指定的图案、文字印刷到指定的产品上，或按自身需要制作的商品（如定制沙发、定制衣柜等）。因此若买家与卖家进行定制商品交易的，建议买家认真查看商品页面标示的商品生产周期、发货时间等信息，并与卖家明确约定好商品的交付时间、交付标准等，避免产生不必要的纠纷。
一、定制商品的处理原则
卖家出售的商品如属于定制商品的，若买卖双方申请京东介入纠纷处理后，京东将根据卖家商品详情页中的描述，以及买卖双方在交易前的约定情况进行判断及处理，定制类商品不支持“七天无理由退货”，但卖家如自行提供退货承诺的情况除外。
【已有清晰约定】
1）若商品确实存在描述不符、质量问题等情况，买家有权向卖家提出退换货申请。
2）除商品确实存在描述不符、质量问题等情况、不符合双方约定的定制要求外，不支持退换货申请，但如卖家明确表明不履行定制约定的情况除外。
3）若买家无正当理由拒绝签收定制商品，应当由买家承担发货及退货运费，及卖家因此产生的损失。
【约定不清或无约定】
1）若买家与卖家未约定具体的交付时间，且卖家商品详情页未就交付时间进行说明的，卖家应当按京东开放平台规定的非特殊商品发货时间为买家进行发货，若卖家未在约定的交付时间内发货的，买家可以申请退款。
2）若买家提出的交付标准不清晰存在冲突，且卖家未与买家进行确认的，买家可申请退货退款，发货及退货运费均由卖家承担。
3）若买家与卖家已约定了具体的交付标准，但买家在卖家开始生产后提出新的需求（该新需求买卖家双方之前并未约定，同时该需求将会导致商品的组成、功能、属性等发生改变），因此引起的纠纷申请京东介入后，京东将根据买卖双方的举证情况，按“谁过错，谁承担”原则进行处理。
二、
定制商品的举证
若买家表示收到的定制商品存在“质量问题”或“描述不符”，买家可按照
《商品质量问题纠纷处理（买家版）》
、
《商品描述不符的纠纷处理（买家版）》
纠纷处理对应专题中的相关举证要求进行举证。
若买家表示收到的定制商品与之前约定的情况存在不一致时，买家需要根据纠纷问题提供相应的证据予以证明商品确实与约定不一致（如咚咚聊天记录等）。
三、定制商品运费纠纷
交易中的运费争议，根据“谁过错，谁承担”的原则处理，但买卖双方协商一致的除外。具体关于退换货问题相应的运费争议，请您查看
《运费问题纠纷处理（买家版）》
。
