# 发票开具规则

>
>
发票开具规则

发票如何修改？
一、自营商品发票
1、订单完成前
（1）支持修改的内容
1）电子发票：可修改的内容为：电子发票添加税号；电子发票抬头更改为人名；电子发票内容明细改大类及大类改明细；电子发票公司抬头更改为个人抬头及个人抬头更改为公司抬头；电子发票修改为增票；
2）增票：可修改的内容为：增票更改为电子发票；
注：非以上发票修改问题，请联系京东客服处理。
（2）修改路径：
我的订单
-修改发票或
我的订单
-订单详情-修改发票
2、订单完成后
（1）支持修改的内容：订单完成后2年内可支持修改，具体可修改的内容如下：
1）电子发票：可修改的内容为：电子发票添加税号、地址、电话、开户行及账号；电子发票抬头更改为人名；电子发票内容明细改大类及大类改明细；电子发票公司抬头更改为个人抬头及个人抬头更改为公司抬头；
2）增票：可修改的内容为：增票更改为电子发票；
注：非以上发票修改问题，请联系京东客服处理。
（2）修改路径：我的京东-客户服务-
我的发票
二、第三方卖家发票
发票问题请联系卖家确认。
