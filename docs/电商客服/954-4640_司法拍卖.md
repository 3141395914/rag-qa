# 司法拍卖

>
>
司法拍卖

【司法】竞价流程介绍
阅读公告：
请仔细阅读公告，充分了解标的物实际情况。
实地看样：
如需实地看样，请注意查看法院的联系方式、看样时间及注意事项，并及时与法院联系。
交保证金：
参与竞价前，请认真阅读标的物详情页的《保证金须知》，并按照页面公告的方式按时缴纳保证金。
建议您提前1-2个工作日缴纳保证金，完成支付后，刷新标的物页面即显示等待开拍出价。
开始竞价：
确认出价金额，点击“出价/去出价”按钮进行出价。
竞价成功：
您可以在京东拍卖频道右上角点击进入“个人中心”查看所有已报名并交纳保证金的拍品以及竞拍成功的拍品，并看到对应拍品的状态。如果您已竞拍成功，可在此处查看已拍下的拍品，并支付相应订单金额，完成付款。
款项支付
：竞价成功后，用户缴纳的保证金将自动转化为部分成交款，由京东结算给法院（标的详情页面另有规定或各方另有约定除外）。
竞价成功：
请在法院规定的期限内支付成交尾款，并联系法院办理后续的交割事宜。
