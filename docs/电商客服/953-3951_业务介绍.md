全球售业务支付问题
Q1：
京东全球售购物支付方式？
京东全球售支持使用JCB、万事达、VISA等多种国际信用卡支付，同时也支持微信、香港八达通、中国银联等支付方式支付，带给用户便捷的购物体验。
Q2：中国大陆地区账户支持的支付方式？
支持的支付方式，请查看链接：
https://help.jd.com/user/issue/list-173.html
Q3：国际信用卡支付付款？
选择国际卡支付，点击立即支付后直接跳转到国际卡支付页面，填写完整信息后，即可完成支付。

退款：
如您用信用卡支付，退款会在1-15工作日退回到您账户；
借记卡支付，退款会在1-7工作日退回到您账户。
Q4：用国际卡支付时若出现重复支付该怎么办？
系统会自动甄别您的重复支付，如系统判定为重复支付，在当天系统对账时会发现，并自动触发退款操作。如您用信用卡支付，退款会在1-15工作日退回到您账户；借记卡支付，退款会在1-7工作日退回到您账户。
若存在退款异常的情况，您可以联系京东全球售客服。
Q5：京东购物汇率如何换算？
汇率是按照您发卡银行的汇率自动换算的，如果有任何问题，请与您的发卡行进行联系。
Q6：如何使用八达通进行支付？
1. 八达通目前仅支持购买京东自营商品（不支持虚拟类交易），且收货地址为香港地区时使用。
2. 京东商城APP支付：
提交订单→选择八达通支付→跳转至八达通APP并登录→完成支付
1）	收银台页面展示选择八达通付款方式
注：人民币与港币参考价格的展示
页面最底部，展示参考支付的HKD价格及所用的转化汇率（汇率为实时汇率，仅供参考所用，最终付款金额，以八达通的显示为准）
2）点击八达通支付，跳转至八达通APP，登录APP完成支付
（Android手机必须具有NFC功能；IOS手机需要配对八达通流动读写器；使用O! ePay需要先通过八达通APP登录O!ePay账户。如八达通的下载及使用有任何问题，请联系八达通客服咨询(邮箱：customerservice@octopus.com.hk)
3. 京东商城PC端JD.COM支付：
1）收银台页面展示选择八达通付款方式
注：人民币与港币参考价格的展示
将鼠标放置于八达通支付处，即可展示参考支付的HKD价格及所用的转化汇率（汇率为实时汇率，仅供参考所用，最终付款金额，以八达通的显示为准）
2）展示“八达通”卡的二维码和PC读卡器
2.1） 扫码支付
登录八达通APP客户端→扫描二维码→选择付款方式→完成支付
2.2 ）八达通卡拍卡支付
如PC配备了八达通卡的读卡器，可直接拍卡进行支付。
4. 八达通使用须知
1）目前八达通仅支持购买京东自营商品（不支持虚拟类交易），且收货地址为香港地区。
2）八达通支付二维码有效期为30分钟，如30分钟内未支付完成，二维码会失效，需要重新付款，生成新的二维码/支付短码。
3）使用八达通支付，不收取客户任何手续费。
4）八达通支付后如订单显示【等待付款】，若八达通系统中显示未扣款，该笔金额将由八达通自动退回；若八达通系统中确实已扣款的，请在1个工作日内关注款项是否支付到该笔交易中，若1个工作日后交易状态未变更或交易状态未变成【交易已付款】的，请联系京东全球售客服协助处理。
5）八达通的退款有效期是180天，超过180天的退款，是不支持原路退回的，可支持退款至客户京东账户余额中。
退款时效：八达通APP将在3-5个工作日内向您发出接收退款通知
---如您使用八达通卡付款，请您注意查收消息并拍卡确认收款；
---如您使用O! ePay账户付款，退款会直接打入O! ePay账户余额中。
退款汇率：按您使用八达通支付时的汇率计算。
