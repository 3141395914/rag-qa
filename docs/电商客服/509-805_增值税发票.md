# 增值税发票

>
>
增值税发票

什么商品可以开具增值税发票？
京东自营商品(部分特定商品除外)和少部分第三方卖家商品可以开具增值税专用发票，具体还请您以您选择的商品以及选择的发票类型为准。
注：第三方卖家商品开增值税专用发票，需先联系第三方卖家客服确认。
根据财税[2021]10号规定，自2021年1月1日起至2023年12月31日，免征图书批发、零售环节增值税。纳税人销售免税货物不得开具专用发票，故目前图书不开具增值税专用发票。
根据国家税务总局增值税发票管理规定,商业企业一般纳税人零售的烟、酒、食品、服装、鞋帽（不包括劳保专用部分）、化妆品等消费品不得开具专用发票（国税发【2006】156号）。因此，您采购上述产品的订单将无法取得增值税专用发票。
