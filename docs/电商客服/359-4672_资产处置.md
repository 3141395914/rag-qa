资产处置

资产处置竞价流程
阅读公告：参与竞价前，请仔细阅读公告，充分了解标的物实际情况
实地看样：如需实地看样，请注意查看处置机构的联系方式、看样时间及注意事项，并及时与处置机构联系
交保证金：参与竞价前，请认真阅读标的物详情页的《保证金须知》，并按照页面公告的方式按时缴纳保证金
开始竞价：确认出价金额，点击“出价/去出价”按钮进行出价
竞价成功：您可以在频道右上角点击进入“个人中心”查看所有已报名并交纳保证金的标的以及竞价成功的标的，并看到对应标的的状态。如果您已竞价成功，可在此处查看所获拍的标的，并支付相应订单金额，完成付款
款项支付：竞价成功后，请按《竞买公告》或《竞买须知》内规定的时间完成支付， 否则系统会取消订单，并将此次竞价结果按照违约处理
竞价成功：准备所需证件并与资产处置机构确认时间办理交割
