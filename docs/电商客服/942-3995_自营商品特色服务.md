大家电“一价全包“安装服务产品说明
一、产品定义：
客户选购有“一价全包”标识产品，且非商业用途使用时，后续安装服务过程中客户将享受产品内容中所承诺的服务项目上门免费服务，如：人工费用、辅材费用以及其他高空作业费用、打孔费用、远程上门服务费用等，具体项目明细详见项目内容。

三、服务说明：
1、“一价全包”包含内容
1）辅材类免费项目：服务过程中常用辅材如支架（定制/异形支架等除外）、漏电保护开关、加长铜管、PPR管、弯头、接头、角阀等辅材，具体免费项目及要求以前台商品页面展示内容为准。
2）服务类免费项目：服务过程中涉及到的常规高空作业费（吊人、吊车等特殊设备除外）、打墙孔费（不包括大理石、玻璃、保温板、瓷砖及木板等特殊材质墙体）、远程服务费、拆旧机费等特殊 服务项目，具体免费项目及要求以前台商品页面展示内容为准。
2、非免费项目
安装过程中涉及到的特殊辅材或服务，如拆装防护网、租赁吊篮吊车等特种设备以及未在页面“一价全包”产品包含项目内的辅材及服务费用。
3、“一价全包”可适用范围
1）适用商品范围：在京东商城购买的大家电，由京东定制原厂安装，非商业用途使用，且支持“一价全包”服务的商品。
2）一价全包服务仅限购买支持“一价全包”的新机的首次安装，如出现二次安装的情况，按正常收费标准进行收费。
3）“一价全包”服务申请时间：自订单签收后3个月内（以商品送达后第二天0点开始计算）可申请服务；
4、“一价全包”不可适用范围
1）企业用户购买的商品、商业用途使用而购买的商品；
2）与产品内容不符的超规格或客户要求的其他特殊材质安装辅材、特殊 服务项目；
3）包含高空作业的服务产品中高空作业过程中涉及到的脚手架、吊篮、吊车等特殊设备租赁服务及费用；
注：“一价全包”产品内容不可转让、抵扣、折现；批量工程机（单一地址＞10套）不能享受此产品服务。
