资产处置

企业用户参拍流程
企业用户参拍注册——电脑端
1.
打开京东首页PC端，在右上方，点击“免费注册”按钮，选择企业用户注册
2.
仔细阅读并同意《京东企业用户注册协议》《京东企业用户隐私政策》，填写单位名称、手机号，完成短信验证并注册
3.
企业用户提交注册申请后，需要等待账号审核，审核周期为工作日，24小时之内。
企业用户参拍注册——手机端
1.
打开京东首页下方，点击“立即登陆”按钮；
2.
选择新企业用户注册，填写手机号，仔细阅读并同意《京东企业用户注册协议》和《订单共享与安全》；
3.
填写账号密码，完成短信验证，仔细阅读并同意《京东企业用户注册协议》
4.
填写公司名称，完成注册。
企业用户实名认证
京东企业用户账号审核通过后，需要对该企业账号进行企业实名认证，企业实名认证由京东金融提供在线实名认证的提交及审核，
审核周期为2个工作日
。
登录企业账号后，在标的物页面点击“交保证金报名”按钮。
点击页面底部的“立即绑定/注册企业钱包”按钮，绑定京东金融企业账号，若无已注册京东金融企业账号，可在跳转页面直接注册。
输入需要绑定的京东金融企业账号，若无已注册京东金融企业账号，则输入用户名进行京东金融企业账号的注册与绑定。
输入要注册的用户名、密码、手机号、图形码，点击“发送验证码”，根据手机短信内的验证码，正确填写后，点击“立即注册并绑定”。
成功注册并绑定京东金融企业版账号后，页面自动跳转至京东金融企业版首页，点击顶部实名认证提醒，进行企业实名认证。
选择企业类型和企业证件类型，点击“下一步”
根据页面提示。上传统一社会信用代码证、银行开户许可证。
上传法人身份证正反面，填写被授权人身份信息，可勾选为（授权人同法人），填写联系人手机号，店铺审核或驳回后，会发送短信至该手机，点击“下一步”。
仔细确认待确认提交的企业用户信息，确认与各资质证照所列的信息内容无误后，点击“确认提交”按钮，等待审核。
提交成功后，页面会提示认证提交成功，企业实名认证审核周期为2个工作日，若竞拍标的物已开拍，或标的物距结束时间不足2个工作日时，可记录下实名认证顶部所显示的9位数字商户号，拨打京东拍卖客服专线400-622-9586，将该商户号提供给客服，客服会在第一时间联系相应的运营经理，做加急处理。以保证企业用户能够顺利参拍。
