# 司法拍卖

>
司法拍卖

【司法】企业用户参拍流程
一、注册京东商城企业用户账号——电脑端
1.
点击京东司法拍卖首页（https://sifa.jd.com）顶部的免费注册按钮，进入到注册页面
2.
跳转到注册欢迎页，根据竞买人的竞买主体，选择企业用户注册。
3.
填写账号注册信息
4.
仔细阅读并同意《京东企业用户注册协议》《京东企业用户隐私政策》，填写单位名称、手机号，完成短信验证并注册
5.
企业用户提交注册申请后，需要等待账号
审核
，审核周期为工作日，24小时之内。
二、注册京东商城企业用户账号——手机端
1.
打开京东首页下方，点击“立即登陆”按钮；
2.
选择新企业用户注册，填写手机号，仔细阅读并同意《京东企业用户注册协议》和《订单共享与安全》；
3.
填写账号密码，完成短信验证，仔细阅读并同意《京东企业用户注册协议》
4.
填写公司名称，完成注册。
二、企业通过实名认证缴纳保证金
1.
企业参拍需要先注册京东企业账号，企业账号审核通过后才可以正常登陆京东，审核周期通常为
2
个工作日。登录企业账号后，在对应的标的物页面点击“交保证金报名”按钮，跳转到企业实名认证界面，需要点击立即绑定/注册企业钱包按钮。进入到《司法拍卖用户竞拍服务协议》在线签署页面，勾选“我已阅读并同意《司法拍卖用户竞拍服务协议》及本场《竞拍须知》”，点击“企业实名认证”按钮。
2.
绑定注册京东钱包后可以直接登录京东钱包企业版在顶部点击“实名认证”按钮。
3.
根据页面提示所需要填写的内容，按照真实信息如实填写，务必按照营业执照、银行开户许可证等内容如实填写。
三、提交保证金
1.
完成上面一系列操作后，可以进入收银台支付保证金，可以选择企业网银或者企业转账两种支付万式。
注：建议用上述十一家银行的企业网银进行在线支付，如使用企业网银所属银行不在此列，则点选“企业汇款"。
*
按页面提供信息，进入企业网银转账汇款至指定账户即可
*
转账需将此汇款识别码填写至电汇凭证的【汇款用途】、【附言】【摘要】等栏内，用于系统自动识别款项作为司法拍卖保证金用途。
