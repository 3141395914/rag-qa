# 自营商品特色服务

>
>
自营商品特色服务

京东自营服饰材质保障服务
一、服务介绍
您选择带有“材质保障”标识的京东自营商品，如经指定机构检测，检测结果为产品材质与衣服标签上标注的材质不一致，将补偿商品的实际支付金额（包含检测费与邮寄费）。
二、服务流程
出险报案-商品检测-资料提交-保险公司审核-理赔到账
三、服务有效期
商品收货180天内（以订单完成次日开始计时）可申请服务。
四、服务说明
1、如果您质疑购买商品材质，可在商品收货180天内（以订单完成次日开始计时）向保险公司报案（报案电话：95511，24小时服务）。
2、电话报案后，需将购物凭证、发票、检测报告、送检过程照片、产品残值照片、相关收据等一并提交审核，如资料提供齐全，保险公司预计24小时内审核通过。
备注：具体需提供材料以保险公司要求为准
3、如检测结果为商品材质与商品标签上标注的材质相符，则相关费用（包含检测费与邮寄费）由您自行承担。
