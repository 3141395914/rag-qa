# 司法拍卖

>
>
司法拍卖

【司法】出价规则
1、当您开始出价竞拍时，首先需要确认您的出价金额，若拍品尚未有人出价时，您可按起拍价出价，也可以在起拍价基础上加一个或多个加价幅度出价。
2、若拍品已有人出价时，您可在当前价格的基础之上加一个加价幅度出价，也可以手动在当前价格基础上加多个加价幅度出价；当您确认好价格以后，就可以点击"出价”按钮进行竞价。
3、参与司法拍卖时，在竞价过程中，可支持在您出的最高价基础上连续出价，但出价前需您进行二次确认及验证。
4、对于处于变卖阶段的拍品，第一个参与竞拍的用户出价后，拍卖结束倒计时会自动变为24小时，其他出价规则不变。
5、对于设置了延时周期的拍品，当标的物的竞价时间只剩最后5分钟时，如果有竞买人出价竞拍，该标的物的竞价时间在此次出价的时间基础上自动延时5分钟（具体以标的物详情页的倒计时为准），直至无人再次出价时，竞价结束。
例如：假设标的物的竞价结束时间是6月18日10点整，如果在6月18日9点56分18秒，有竞买人甲出价，那么系统将竞价结束时间自动延长至6月18日10点01分18秒。如果在6月18日10点01分05秒又有竞买人乙竞买人甲出价的基础上进行出价，那么系统将竞价结束时间自动延长至6月18日10点06分05秒……以此类推，直至最后5分钟内，没有新的竞买人出价，该标的物的竞价结束。
6、竞拍结束后，出价最高且超过保留价的参拍人竞价胜出。如您竞拍胜出，则可按照机构公告和系统提示进行到下一步骤。
