# 订单修改常见问题

>
>
订单修改常见问题

下单后可以修改订单吗？
1.
部分状态下可修改地址、收货人信息或配送时间，您可以在京东账户-我的-我的订单-订单详情查看是否有“修改订单”按钮（点击右侧进入【
我的订单
】），如有则说明订单可以修改。如果没有此按钮，说明该订单不可修改。
2.
地址修改，地址一般可修改末级地址及详细地址，涉及跨区域地址则不支持修改，不同省市可修改地址范围不同，具体以修改页面展示为准。
3.
配送时间修改，中小件订单一般
可延后配送
1-7天的时间，大件订单一般可
延后配送1
-90天的时间，根据用户收货地址不同，具体可修改范
围可能会有
不同，具体以修改页面显示为准。
4.
订单修改成功后，商品出库及配送时效会按照修改后的时间进行重新计算。
5.
订单修改成功，以修改提交后，在订单跟踪信息里显示“温馨提示：您的订单修改成功，订单信息将稍后更新”为准，以下特殊场景不支持修改订单：
非自营实物订单、非京东配送订单、特殊类型订单（包含不限于极速达、定时达、上门自提、预售、秒杀等
，具体以修改页面展示为准
）。
注意：
1.
您在京东下单后，支付方式及商品数量、颜色、型号、品类等商品信息无法进行修改。
2.
部分渠道（如微信小程序、手机QQ等）可能无修改入口，您可尝试到京东APP或网站（https://www.jd.com）进行修改。
3.
由于系统订单流转较快，可能会存在系统已提示您修改成功，但实际商品已按照修改前地址配送到站点或原地址的情况，如发生前述情况，您可以联系京东客服进行处理。
4.
订单原有下单时享受的促销活动，在修改订单时将以当前商品信息为准，修改时请注意查看活动信息，避免修改后造成原有活动无法享受。
