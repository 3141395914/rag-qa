# 自营商品特色服务

>
>
自营商品特色服务

为什么无法享受闪电退款？（自营商品）
1、商品京东价格（非实际支付价格）已经超过客户的闪电退款授信额度；
2、使用分期 、白条等信用付款方式，或货到付款POS机刷卡、现金支付将无法享受闪电退款；
3、定制类、虚拟类、夺宝岛商品、珠宝、钟表、奢侈品类、大家电类等商品不支持闪电退款；
4、近90天内拍下未付款订单过多；
5、违反了下面任意一条内容的将永久无法使用闪电退款服务：
（1）利用闪电退款诈取财物；
（2）返回的商品有人为损坏的或者缺件少件的；
（3）发起还款通知后仍不还款；
（4）在闪电退款流程中如用户存在不诚信行为，例如，没有把商品返回京东，骗取商品货款等行为，客户魔镜等级将降级为最低等级且不可再升级，同时，用户将不再具有享受本服务的资格，无法享受闪电退款和其他售后特色服务。用户是否可享受本服务，请以售后审核结果为准。
