京东交易条款

京东集团品牌授权管理规范
总则：
1.
京东集团一切品牌，对外授权均需要经过集团各级品牌、法务、公关等管理部门审核，京东集团品牌管理委员会作为京东集团品牌管理工作最高管理部门，对一切品牌授权行为拥有最终决策权。
2.
品牌授权原则：
（1）
实事求是：一切品牌授权必须基于合作事实，基于被授权方的资质事实进行授权。
（2）
最小必要授权原则：遵循最小必要的授权原则，即基于真实必要的业务需求授权第三方在最小范围内使用品牌。无商务合同、无业务合作不授权。
3.
授权申请部门为第一责任部门，负责授权全流程把控，包括：授权前期的对被授权方的资质调研和风险评估、授权期限内的监督和管理、授权接受后的京东品牌资产回收等维权工作。
4.
如品牌授权涉及资本层面的合作，需要集团投资部门出具品牌估值报告。
5.
京东的一切品牌授权，不得进行转授权。
6.
京东的一切品牌授权审批，从严不从宽。
一、品牌授权的定义和范围
品牌授权是指授权者将自己开发和/或使用的商标、品牌、标志、吉祥物以及其他商业标识等以合同或授权书等法律文件的形式授予被授权者使用；被授权者按合同或授权书等法律文件规定从事经营活动（通常是生产、销售某种产品或者提供某种服务）。包括但不限于：生产授权、招商授权、经销授权、联合活动、信息发布、资质认证等。
二、品牌授权的文件
1.
合同：按照公司合同审批流程进行审批。如果合同中有关于品牌授权的描述和约定需要品牌部门前置评估，法务团队可以加签品牌团队前置评估。
（1）
合同签署过程中，所涉及的合同不涉及具体、明确的品牌授权约定的，视为合同不涉及品牌授权，合同签署审批过程无需品牌团队参与评估，待具体品牌授权条件满足时，按正常品牌授权审批流程执行审批，需要签署相应补充协议的应签署补充协议或文件；
（2）
合同签署过程中，涉及具体、明确的品牌授权条款，视为合同与品牌授权同时进行，法务部门、品牌管理团队等相关部门需同步评估是否满足品牌授权规则，在满足规则的情况下签署合同并同步进行品牌授权流程。
2.
授权书：目前通过brand平台审批，集团各级品牌部作为主审部门，酌情加签法务部门、公关部门等进行联合审批。
3.
授权书的出具原则上需要合作双方已签署合同作为必要前提。
三、品牌授权评估
品牌授权以“风险控制”为评估衡量维度，基于风险控制，可以将被授权方分为两类，即：被授权方的
所有权属于京东
和 被授权方的
所有权不属于京东
。
1.
所有权属于京东：则可控性很高，主要表现为京东集团对京东全资子公司的授权管理。
2.
所有权不属于京东：则可控性较低，主要表现为京东对第三方合作伙伴的授权管理，包括但不限于：京东战略投资企业，京东控股企业，京东合作企业等。
3.
对于加盟类业态，包括线下业态和线上业态，必须满足100%从京东自营进货或通过使用京东的数字化系统，实现对商品和服务的100%把控。否则不得使用京东的品牌资产。
4.
在满足上文条款的基础上，其他评估维度参加附件《京东集团品牌授权评估表》

五、自媒体授权管理
1.
自媒体授权需要单独审批。合作方获得京东生产授权、经销授权等并不能自动获得自媒体授权。即，京东家电专卖店XX店的加盟商不能以“京东家电专卖店XX店”的名义开设自媒体账号。
2.
带有内容传播的自媒体账号，原则上不向第三方开放，不对外进行授权。
3.
纯销售类的自媒体账号，参照“加盟类业态”的评估办法进行评估。
