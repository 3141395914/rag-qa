售后服务细则（自营）

运动健康类商品售后服务细则（自营）
适用范围：
运动鞋包、运动服饰、健身训练等
退换货时限：
自实际收到商品第二日起7日内可退货，15日内可换货。
退换货原因：
1.商品质量问题。
2.7日内在商品（含附件）完好前提下申请无理由退货。
注：
注意事项中约定不适合退换的商品除外，特殊规则以商品详情页介绍为准。
售后流程：
注：
审核通过后，请您将商品、附件、发票、包装、赠品，一并返回京东，核实属实后，办理退换货手续（电子发票无需返回）。
注意事项：
1.因个人原因造成的商品损坏（如自行修改尺寸、洗涤、皮具打油、刺绣、长时间穿着等），不予退货；
2.
贴身货品，如内衣裤、袜子除质量问题外，不支持无理由退货
3.商品防伪标识码刮开或撕损，商标标识、吊牌撕毁，或商品被洗涤、有脏污等，不支持7天无理由退货；
4.退货时赠品需一并返回京东，如赠品缺失，则主商品无法全额退款（换货无需返回）。
