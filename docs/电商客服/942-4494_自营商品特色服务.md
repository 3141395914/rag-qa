# 自营商品特色服务

>
>
自营商品特色服务

安装无忧-安联（已失效）
一、服务介绍
当您购买带有“安装无忧”的自营商品时，并到门店进行安装服务，因安装时操作不当，造成您安装的车辆/车辆上的装饰物品/汽车配件等损坏的，将对您产生的直接损失进行补偿，补偿最高限额为5万元，补偿费用具体以直接的实际损失为准。
二、服务流程
发生事故→电话报案→准备材料→保险公司校验→补偿到账
1、 发生事故：如果您购买带有“安装无忧”标识的自营商品后，安装门店在提供服务过程中对您的车辆/车辆上的装饰物品/汽车配件等造成损坏，视为发生事故；
仅针对为您提供安装订单对应门店在提供相应安装服务时发生的保险事故进行勘察及理赔。
2、 电话报案：您可在事故发生后打理赔热线（理赔热线：400 800 2020-1-3-3）发起理赔申请。
3、准备材料
（1）完整填写的索赔申请表
（2）安装服务的订单截图，需包含订单号；
（3）车主身份证复印件；
（4）行驶证复印件；
（5）事故照片（车架号、带车牌的全车照，损失部位）；
（6）维修费用的凭证（车辆维修工单及维修发票）；
（7）重新购买配件的购物清单及发票；
（8）特殊情况需提供鉴定报告，相关法律文书或事故证明。
4、保险公司校验：保险公司对材料进行校验，并联系您沟通校验结果；
5、补偿到账：保险公司审核通过后，将理赔款项打入您提供的银行账户。
赔偿上限：每个服务订单每次事故及累计补偿限额5万元。
注意事项：如果有系统记录证明安装门店已经赔偿您的实际损失，保险公司将不再对您进行重复补偿。
三、服务有效期
1、生效时间：服务码激活次日零时保险生效。
2、保障期间：服务码激活后30个自然日内有效。
四、温馨提示
（1）买家受益人及其代表的故意行为或欺诈行为，不可抗力的自然灾害，不在服务范围；
（2）车内物品的丢失，不在服务范围；
（3） 其他除外责任详见商品介绍页《保险条款》
