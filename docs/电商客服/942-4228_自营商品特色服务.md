什么是免费问宠医？（自营商品）
一、 服务介绍
客户选购有“免费问宠医”标识的自营商品，如有健康养宠、爱宠疾病预防、健康指导等非商品问题，可以通过商品详情页下方“免费咨询宠物医生”入口对京东严选的宠物医生发起问诊咨询，或与在线客服沟通索要“问宠医”链接，免费问诊咨询。
二、 服务流程
进入 “免费咨询宠物医生”页面——与宠物医生进行30分钟不限次沟通——服务完成
三、 服务说明
1.      平台与宠物医生只针对宠物健康咨询问诊提供专业建议，不构成活体购买依据。
2.      “免费问宠医”服务不涵盖对商品质量、商品规格、价格促销、售后退换货处理等商品类服务。旨在通过在线轻问诊的形式为用户提供健康指导、用药建议、疾病预防专业咨询、体检报告解读、二次辅助诊疗等专业咨询服务，为安心养宠保驾护航。
3.      在“免费问宠医”服务中所建议使用的疫苗针剂类商品，请务必在专业人员指导下使用。
4.      如客户有利用本服务牟利的行为，将取消客户享受此服务的权益，并将影响客户京东账号的信誉等级。
