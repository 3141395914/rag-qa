# 增值税发票

>
>
增值税发票

如何更新/修改增票资质？
您好，若您需要变更已提交过的增票资质信息，您可以点击“我的京东--账户设置--
增票资质
”，
按照以下方法进行操作：
1、资质审核结果为【已提交，等待审核】：修改资质全部信息/纳税人识别号时，需先点击【删除】按钮，然后重新填写新的资质信息，修改部分资质信息或非纳税人识别号时，可点击对应修改信息后方的【修改】按钮重新填写新的资质信息。
2、资质审核结果为【已通过审核】：
修改纳税人识别号信息时，需点击【删除】按钮，重新填写新的资质信息
；修改除纳税人识别号以外的其他信息时，点击【修改】按钮，重新填写新的税号信息，最后点击【确定】按钮，资质审核状态变为【已修改待审核】即表示已经操作修改完成，等待审核即可。
注：
为了防止倒票行为发生，降低税务风险，且考虑到一般情况下公司资质信息不会随意变更，故
增票资质审核通过30天后方可进行删除
。请您放心，如您有删除的需求，可在原资质审核通过30天后及时操作，我们会尽快为您处理。
3、资质审核结果为【未通过审核】：点击【删除】按钮，重新填写新的资质信息即可。
