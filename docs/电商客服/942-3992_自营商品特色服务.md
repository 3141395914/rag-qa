# 自营商品特色服务

>
>
自营商品特色服务

什么是效期无忧服务？（自营商品）
一、服务介绍
客户选购有“效期无忧”标识的自营商品，如在订单签收后至指定时间内发现商品的有效期不符合对应效期要求，可以在线提交售后申请或者联系客服申请，并提供有效凭证，经审核通过后可为客户提供如下服务：
生鲜商品不符合效期要求，且剩余保质期不足保质期的1/2时，将为客户申请补贴，非生鲜商品不符合效期要求时，将根据商品情况为客户进行退货退款。
二、服务流程
客户在线申请售后或联系客服申请-上传有效凭证-京东审核-京东上门取件/申请补贴-退款退货/补贴成功-服务完成
三、申请时间（指定时间）
1、非生鲜商品：自订单签收后30天（以商品送达后第2天0点开始计算）内可申请服务；
2、生鲜商品：自订单显示签收之时起的48小时内可申请服务。
四、效期要求
客户签收商品之日起（包含签收当日）商品的剩余保质期时长不满足如下要求：
非生鲜商品：
1、奶粉/医药保健类的商品，保质期剩余时长大于等于120天。
2、母婴营养辅食类商品，保质期剩余时长大于等于保质期的1/4，小数点四舍五入取整。
例：商品保质期为365天，保质期剩余时长大于等于保质期的1/4（91.25天），四舍五入后即保质期需大于等于91天
3、美容护肤、香水彩妆/美妆工具类商品，保质期剩余时长大于等于90天。
4、食品饮料类商品：
1）粮油调味类商品，保质期剩余时长大于等于保质期的1/2，小数点四舍五入取整；
2）饮料冲饮类商品，保质期剩余时长大于等于保质期的1/3，小数点四舍五入取整；
3）休闲食品类商品，保质期剩余时长大于等于保质期的1/5，小数点四舍五入取整；
生鲜商品（新鲜水果、蔬菜蛋品、精选肉类、海鲜水产、冷饮冻食类商品）：
1、保质期为7天以内的商品，签收商品之日起（包含签收当日）商品的剩余保质期时长不少于3天。
2、保质期为8-15天的商品，签收商品之日起（包含签收当日）商品的剩余保质期时长不少于4天。
3、保质期为16-30天的商品，签收商品之日起（包含签收当日）商品的剩余保质期时长不少于商品保质期1/4天数，小数点四舍五入取整。
4、保质期为31-75天的商品，签收商品之日起（包含签收当日）商品的剩余保质期时长不少于商品保质期1/5天数，小数点四舍五入取整。
五、申请服务的有效凭证
1、非生鲜商品：
1）客户购买的商品外观照片和商品生产日期处照片；
2）商品原重80%以上的商品照片。
2、生鲜商品：客户购买的未拆封使用的商品外观照片和商品生产日期处照片。
六、服务说明
1、非生鲜商品：若不符合效期无忧服务要求时，将视商品情况为客户提供退货退款服务。
客户申请退回的，其剩余容量、数量不应少于原容量/数量的80%。如有赠品，则赠品需一并退回，且剩余容量、数量不应少于原容量/数量的80%。
2、生鲜商品：若不符合效期要求，京东审核通过后，将会为您申请可抵扣未拆封商品实付金额30%的对应价值的京豆作为补贴，补贴将发放至您的申请账户中，无需返回商品。
客户申请补贴的生鲜商品，其外包装应为未开封的，已开封的商品不予补贴。
3、以上效期无忧服务仅针对客户购买的主商品，不适用于赠品。但相关赠品应符合本规则的要求。
4、客户需确保上传的申请凭证为原图，且须确保内容真实有效、未经涂改和增删，如果相关凭证有人为修改的痕迹或存在其他虚假情况的将被视为无效凭证，将无法享受效期无忧服务。
5、如客户有利用此服务进行牟利等不正当行为的，京东有权取消客户享受此服务权益，并将影响客户京东账号的信誉等级。
6、若您申请上门取件的地址超出了京东上门取件的范围，需要您自行委托第三方快递邮寄到京东指定地址，且请勿使用货到付款方式。在您提供有效订单号、快递单号及费用凭证，并且由京东审核通过后，运费将以余额或京豆的方式返还到您的京东账户。
